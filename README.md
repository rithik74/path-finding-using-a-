# A* Pathfinding Visualizer

A web-based interactive tool to visualize the A* (A-Star) pathfinding algorithm in action.

## Features
- Interactive grid where you can place the start and target nodes, and draw walls/obstacles.
- Visual representation of the A* algorithm exploring nodes to find the shortest path.
- Clear and color-coded visualization of the visited nodes and the final path.

## How to Use
1. Clone the repository and open `index.html` in your web browser.
2. The start and target nodes have default positions but can be adjusted (depending on implementation).
3. Draw walls on the grid where the path cannot cross.
4. Click the "Visualize" or "Start" button to see the algorithm in action!

## Tech Stack
- HTML5
